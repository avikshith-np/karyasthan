# The weekly review (plan 020 E4)

Each week a sample of what his writers wrote goes into a queue; the owner marks it PASS / FAIL, one card at a time, on Control · Review (`#review`). It measures the writing, calibrates the claim check (E3) and feeds the incident suite (E2). Sampling is code: no model call anywhere here.

- **Files** — `src/memory/reviewStore.js` (the one store), `src/dashboard/routes/review.js` (the one route file, and an hourly unref'd timer that samples), `pages/review.js`, `guides/review.js`. Migration v21 (`review_items`, `review_weeks`). Tests: `npm run test:review`, `edges.js --only review`.
- **Sampling** — `ensureWeeks` takes the last two finished weeks not yet closed (Monday to Sunday in the bot's time zone); `SAMPLE_PER_SURFACE` = 25 per surface, a stable shuffle (sha256 of week, surface, id), one per day in turn, every phrase once before a repeat. SAMPLE THIS WEEK SO FAR takes the current week now; the finished week tops it up to 25. An output is sampled once, ever.
- **A row is a pointer** — surface + source id, never words, never a JID. Text is read from the source each time, so a revert, a rewind or a purge takes it along. `liveRow` is the one check: the source's status, plus `event.reverted` / `redacted` on its event, because a source's own status only catches up at the next tick. An undone output leaves the queue; a mark it already had stays counted (UNDONE in the results counts the unmarked ones).
- **Who is never sampled** — real people (`subject_jid`, `mode: self_only`), anything from a chat (origin not self / owner), the owner's own words in a thread (`tier` NULL, or `caller` NULL: the gist line that stands in for a model turn), a row with no text, a dream still waiting for words.
- **Private** — `isPrivate`: a scene or text whose event's `heat` isn't `tame`, a `desire` caller, tone `naughty`, or a writer output with no known heat (fails closed). The queue carries no text for it; `GET /api/review/items/:id/text` is the tap, and it can't be marked unread. It never goes in an export. Thoughts and dreams have no register, so they aren't private. This store can't import `story/desire.js` (facade guard), so it reads what the log recorded.
- **Expiry and cost** — an unmarked card goes after 12 weeks (`expireOpen`, on the sampling timer); a mark is never dropped. An expired card no longer counts as sampled in its week. Calls over many items read the reverts once (`revertedEvents`) and the open items with one query per surface (`liveOpen`), so a neglected queue stays quick.
- **Marking** — once. The same mark again is a no-op, a different one is refused (409 `already_marked`); UNDO LAST (`/unmark`) puts it back. An undone output: 409 `gone`. Notes are fixed codes (`NOTE_CODES`). Write gates as usual; audited with ids and codes (`review.mark`, `review.unmark`, `review.sample`); 120 marks a minute.
- **Offline** — a tap moves on at once; marks wait in `localStorage` `ld.review.pending` (ids and codes only) and go on the `online` event, every 15 s (a dropped tunnel fires no event) and at the next mount. A 400 / 404 / 409 on replay drops that mark and says so. Cards are held in memory only. A private card needs a connection to read.
- **Stubs** — `GET /api/review/failures.json`: `{ v: 1, kind: 'incident-stubs', stubs: [{ id, surface, sourceId, week, note, expect: 'fail', text, sheet?, … }] }`. Private → no text; undone → `gone: true`; a JID in the words or the sheet → `withheld: 'jid'`. They hold his world's names: keep them under `data/`, rename before a fixture is committed.
