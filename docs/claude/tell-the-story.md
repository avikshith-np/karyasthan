# Tell the story UX (spec 017)

Detail moved out of CLAUDE.md (2026-11-02, the file passed Claude Code's size limit). Keep this file current when the feature changes.

The Director's TELL THE STORY panel as a stepper (wish → plan → check his day → done). Design: `specs/017-tell-the-story-ux/plan.md`. Server half:

- **Prompt output** (`POST /api/director/prompt`) adds `planLine` (the plan in one sentence, ≤ 240, built in code by `prompt.js planLineOf` from the drafts' actions, fictional names, places and times — never model text; a new member is "someone new"; null when the route dropped a draft), each draft's `phrase` (the same wording for one draft, ≤ 160, so the page rebuilds the line when a draft is left out) and `bundlePlan` `{bundles: [[draft index…] ≤ 5], after: [bookmark indexes], waiting: [indexes with a status]}` (`promptBundles`: mains in draft order, then side drafts that can ride; a bookmark — never in a bundle — applies after every bundle succeeded; a draft that plans to nothing is left out).
- **Prompt bundles** — the page previews / applies the kept drafts as `{kind:'bundle', actions:[{…action, source:'prompt'}]}` with `source:'prompt'`. `'prompt'` is a `PART_SOURCES` value (planner and route); a `prompt` part (like a `continuity` one) never plans with `relax` (`director.js UNRELAXED_SOURCES`), whatever the preview's relax; the apply audit's `parts` records it.
- **UNDO ALL** — one bundle apply = sibling owner `director.action`s with the same fingerprint and `at`, back to back (`eventLog.directorGroup`). `life.revertChangePreview(id, {group:true})` → the lists over every part + `group`, `actionEventIds`, `parts:[{actionEventId, kind, description, targets, refusals}]`, one fingerprint (a single change keeps its pre-017 fingerprint); `life.revertChange(id, {group:true, fingerprint})` reverts all in one transaction, one rebuild, `story.onOwnerReverted` per change; refused as a whole when any part is past its window. Route `POST /api/director/revert-change {actionEventId, group?: boolean, fingerprint?}` (non-boolean → 400 `bad_group`), audited `director.revert_change {…, group:true, actionEventIds}`. `godView().changes[].groupId` = the first part's id for a bundle's parts, null for a single change.
- **Tests** — `arcs-tests/80-prompt-bundle` (the live breakfast wish → drafts, phrase/planLine, bundlePlan, one prompt bundle applied and audited, a pin stays refused for prompt parts under relax, promptBundles / planLineOf units), `81-group-revert` (siblings, groupId, route preview/stale/revert/audit, the world back to before, one part alone, a part past its window refuses the group).
- **The page** (`pages/life-director-story.js`, mounted by `pages/life-director.js`): steps YOUR WISH → CHECK THE PLAN → MAKE IT HAPPEN → done. Step 2: one card per draft, `cardState` = ready | needs (needs_pick / needs_venue → the venue picker; too_soon with `earliestAt` or a refused preview with a move fix → MOVE TO) | wont (no_route, refusals, a preview that appends nothing) | gone (a side draft whose main was left out) | checking (each draft previewed once, `source:'prompt'`); LEAVE OUT / PUT BACK, NOT IN THE PLAN (left out, `dropped` in words, `cantDo`); the plan line = `planLine` while every draft is kept, else the kept drafts' `phrase`s. Step 3: `bundlesOf(cards)` (mains in draft order, side drafts after their main, ≤ `BUNDLE_MAX`, bookmarks after every bundle) → one bundle preview: the projection in words, continuity as choices (KEEP IT INSTEAD re-previews; HIGH codes and drafts that loosen a control each need a tick — `ticksNeeded`), the free texts again, the story read (auto as `autoStoryRead`) + ADD; MAKE IT HAPPEN applies with the fingerprint, a stale / expired preview is re-previewed and asked again (never applied silently); more than five mains → PART 1 OF 2. Done: UNDO ALL OF THIS → the grouped revert preview (description in a confirm) → revert with its fingerprint. TECHNICAL (localStorage `ld.story.tech`, guarded, off by default): engine words per card + APPLY THIS ONE BY ITSELF (the old preview window). The SCHEDULE panel's venue picks reach the cards through the returned `{prompt, renderPrompt, previewCard}`. `sideLock` / `DROP_REASONS` / `REVIEW_REASONS` are re-exported by `life-director.js`. Tests: `test:dashboard` `tell:` block.
- **Scene facts as of the outing's start** (public-site, same deploy): `projector.stateBeforeEvent(id)` (read-only fold below an id) → `scenes/worker.stateAtStart(session)`: firstMeet, the sheet's people (bands, romance, history, names), the code outcome's weights, prevOf, the job title and `isDate` read the world at the outing's `activity.started`, so a daily pass mid-outing never makes a first meeting look like an old friend; owner intent, place words and the effects read now. REGENERATE recomputes firstMeet from it (keeps v1's outcome). Test: `arcs-tests/76-scenes-before-facts`.
