# Imitate mode

Detail moved out of CLAUDE.md (2026-11-02, the file passed Claude Code's size limit). Keep this file current when the feature changes.

The bot can impersonate a chosen **current member of a group** — their vocabulary, message length, emoji/casing habits, catchphrases, and language mix — built from their real message history. Runtime-only persona swap: `identity.md`/`persona.json` are never written.

- **Engine** — runtime few-shot retrieval, zero LLM in capture: each turn pulls the target's own recent + topically-relevant (FTS) messages from the `messages` table (`recallExemplars` in `src/memory/recall.js`) plus a no-LLM statistical style card (`src/personality/styleProfiler.js`, ~5 min in-memory cache). `buildSystemPrompt`/`buildConversationContext` take an explicit trailing `imitation` argument — resolved once per turn in `processMessage` and threaded down, so dashboard force-respond calls (which pass nothing) never imitate.
- **State** — per-group target in the `group_imitation` table (mirrors `muted_groups`; loaded via `loadImitationModes()` in `src/behavior/imitationState.js`). `active_until` is **NOT NULL** — every activation auto-expires (clamped to `IMITATE_MAX_MINUTES`). Targets are lazily expired and auto-cleared if the person leaves the group. Optional `person_style_card` rows hold an LLM voice descriptor with the build `model` recorded (so a descriptor built during a silent provider fallback is diagnosable).
- **On/off** — the **`imitate` skill** (manifest skill, same pattern as web-search) is the global kill switch; `IMITATE_MODE_ENABLED` is only its boot default (ships `false`). After a restart the master resets to the boot default while unexpired per-group targets persist — flip the master back on and they resume. Per-group targets are set on the group's dashboard page (needs `DASHBOARD_READONLY=false`; every activation is audited as `imitate.on`/`imitate.off`).
- **Pipeline flags** — `postProcess(..., {imitate:true})` skips fixated-word stripping, the generic-reply filter, RNG humanity injection, and ambiguous AI-ism patterns (safety-critical stripping — reasoning artifacts, media/web markers — stays on). The quality gate uses the softer `mentionThreshold` and a believability judge note. Imitation replies are **excluded from `recordQuality`** so they never poison `getQualityInsights()`. The decision engine answers to the target's aliases and (with ≥200 sampled messages) mimics their active-hours cadence; reactions use their top emojis; typing speed scales via `imitationTypingFactor`.
- **Guardrails (enforced in code)** — targets must be current group members (single source of truth: `group_members`); never active in DMs; when the target is the speaker, the bot plays their double (prompt note via `imitation.speakerIsTarget`); activation refused below `IMITATE_MIN_MESSAGES` (default 40); exemplars are scrubbed with `sanitizeWebContent` before entering the prompt (a member message containing a literal `[IMAGE:]` would otherwise trigger a real send); an in-prompt no-harm line forbids money/OTP/password asks and reputation damage; `IMITATE_ANNOUNCE=true` posts a one-time in-chat disclosure (via `actions.js`, honors `DRY_RUN`).
- **Known limits** — warmup gates text before generation, so imitation is inert until warmup allows text (surfaced on the group page). The image-edit fast-path bypasses `generateResponse` and is not imitated. Test with `npm run test:imitate`. Full design: `specs/002-imitate-mode/plan.md`.
