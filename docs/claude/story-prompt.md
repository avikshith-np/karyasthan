# Story prompt (spec 011)

Detail moved out of CLAUDE.md (2026-11-02, the file passed Claude Code's size limit). Keep this file current when the feature changes.

Tell the Director in words (Life · Director, TELL THE STORY). Design: `specs/011-story-prompt/{spec,plan}.md`. Inert behind the `arcs` skill like the rest of the Director.

- **Prompt** (`src/life/story/prompt.js`, `schema.js validatePromptOutput`) — `POST /api/director/prompt {wish}` → ONE `mind` call (caller `director.prompt`; day cap `ARCS_PROMPT_MAX_PER_DAY`, $ cap `ARCS_PROMPT_BUDGET_USD`, `mindBudgetOk`, one at a time) → ≤ 6 drafts of existing Director actions + "can't do yet" lines. Writes nothing: each draft goes through the normal preview → apply. Input = the wish + a code-built catalogue (cast ids + fictional names, places, open arcs, controls, the next 14 days, a 72 h forecast, open windows/goals); never chats, claims, real names or JIDs.
- **The wish check** (`wishProblem`, before any call; fails closed when the names read fails) — JIDs; phone numbers after masking dates (one consistent `-`/`/`/`.` separator — a space-grouped number is never a date) and clock times; real names in any case (a known first name ≥ 3 letters, or a full name). His cast's first names are exempt as a bare token only; a real full name is refused even when a cast member shares the first name. `world.js normalizeName` drops format characters (ZWSP/ZWJ/soft hyphen/bidi) first, for every name check (010 owner text too).
- **Drafts** — heavy stretches, rewind, claims, the reconciler mode and raising `drama`/`heavyLikelihood` are never drafted (R10). APPLY ALL never auto-applies (`batchableOf` → REVIEW INDIVIDUALLY): free-text kinds/shapes, CANCEL TONIGHT / FREE EVENING (`target_resolved`), and anything that can loosen a control — unpin, resume, a fate other than `frozen`, any `drama`/`heavyLikelihood` slider (`loosens_control`; its value was checked against the slider at prompt time only).
- **Bookmarks, side drafts, too-soon outings (audit 2026-10-30)** — the charter drafts a `bookmark` only when the owner asks; backstop `dropUnrequested`: a wish without bookmark / remember this / mark this / save this moment (`asksForBookmark`) drops model bookmarks `unrequested`. **No orphans** (`holdSideDrafts`, run last, after `fillVenueDrafts` / `flagLooksReal`; the route repeats the hold when it drops a main as `route_shape`): a side draft — a bookmark, or one the model marked `"accompanies": <index>` (`schema.js` sets `side`) — carries `dependsOn` (every main draft's index, kept or dropped) and is held (`batchable:false`, `reviewReason:'depends_on_main'`) while any main was dropped, has a status (needs_venue / needs_pick / too_soon / no_route) or is not batchable; a wish with side drafts only is unchanged. The page (`sideLock`) opens a side card only once every main in `dependsOn` is applied there (a dropped or DROP-ped main never is) and APPLY ALL takes mains first. **Too soon**: `dryPlan` keeps an outing the planner refuses `too_soon` / `no_route` as a draft with that `status` (+ `earliestAt` = `outing.earliestStart` for too_soon), never moved by itself, never batchable; the card's MOVE TO EARLIEST rewrites `when` → `startAt` (the page's `movedTo`) and previews. The charter puts "suddenly / now / right away" outings at least prep + the trip (`leadMin`) ahead. Note the planner's own too_soon check is travel-only (`ponrAt < now`), stricter `earliestStart` adds prep. Test: `arcs-tests/59-prompt-orphans` (the live two-action replay, fake geo).
- **Phase 2** — weather windows, rain gear and soft goals: see the "Weather windows, rain gear, soft goals" bullet above. Projector rules worth knowing: `s.weatherWindows` keeps ended windows 24 h, and over 8 drops ended ones before any open one; a rewind whose target lies after a goal's commit but before its outing was over (point of no return or outing past at apply time) expires that decision `{rewound}` (rewind step 4), which cancels it and reopens the goal — never `goal.done` for an outing that was rewound away; `s.soakedAt.travelEventId` keeps the soaked trip, and the "caught in the rain earlier" line waits until that trip is over.
- **Tests** — `arcs-tests/24-prompt` (wish, catalogue, schema, batchable, budgets), `25-weather-window`, `26-goals`, `life-tests/35-weather-window`, `36-rain-gear`.
